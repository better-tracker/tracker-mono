# Functional colour UI variant

Ten SVG screens: login, today dashboard, task creation, subtask creation, profile update — web and mobile. Layouts follow the approved rail-free alternative set.

Colours sampled from the supplied reference image (approximate image values):

| Task meaning | Reference colour | Hex |
| --- | --- | --- |
| Urgent, overdue, high priority | Dawn | #E0A36D |
| Complete | Greenery | #AEB884 |
| In progress | Sea | #BACDD1 |
| Next deadline, due today, parent deadline constraint | Sand | #FED07B |

Login and profile are monochrome. Generic actions, form sections, project selectors, headers and identity blocks are neutral. Task status always has a text label or completion check; text remains pure black. Dashboard retains functional task highlighting, using translucent fills. Subtask status, completion and deadline cues remain contained.

Individual source SVGs retain text. The companion Figma import board outlines typography to preserve its appearance during native SVG import.
